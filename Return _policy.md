1. Decision Flow for Return Policy

START

Customer wants to return an item

Do you have the order details/order number?
NO:  Ask customer to provide order number then END
YES :  Continue

Is the item eligible for return?
NO : Inform customer that the item is not eligible for return then END
YES : Continue

Is the item within the return period?
NO : Inform customer that the return period has expired then END
YES : Continue

Is the item in acceptable return condition?
NO : Explain that the item cannot be returned in its current condition then END
YES :  Continue

Return approved

Provide return instructions/return method

Item received by Northstar

Inspect the returned item

Refund approved?
NO : Inform customer and explain reason then END
YES : Process refund

Notify customer that refund has been processed.

END
