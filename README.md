# Northstar Retail Co. - Support Deflection MVP
**Team:** Pod 45 | **Duration:** 5-Day Industry Sprint

## Project Overview
An automated support deflection prototype designed to handle repetitive customer support inquiries (Order Status, Returns/Refunds, and Stock Availability) for Northstar Retail Co.

---

## Team Commit Message Convention
> **Rule:** Every commit must strictly follow this format. Generic messages like "wip" or "updates" are prohibited.

`<type>: <what changed> - <why it matters>`

### Accepted Types:
* `feat`: A new feature or logical flow.
* `fix`: A bug fix or correction.
* `docs`: Documentation updates (e.g., README, Go-Live note).
* `test`: Adding or updating test cases/simulations.
* `chore`: Maintenance tasks or repository setup.

### Examples:
* `feat: add order lookup logic - enables tracking by order ID`
* `docs: outline go-live note template - prepares handover structure for client`
* `fix: correct stock count calculation - prevents negative inventory outputs`
